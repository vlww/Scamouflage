How it works

  1. 1

    Quick check

    Built-in rules spot look-alike links, fake senders, gift-card and urgency tricks in about a millisecond.

  2. 2

    On-device AI

    Gemini Nano, built into Chrome, reads the message on your computer and streams back a verdict. The message never leaves.

  3. 3

    Cloud only when needed

    If your computer can’t run it, names, emails, phone and account numbers are removed first. Then Gemini in the cloud helps. You always see which one ran.

Built with Firebase AI Logic hybrid inference, App Check, Remote Config, Authentication and Cloud Firestore.

Privacy, plainly

  • On-device by default. When your computer can run Gemini Nano, your messages are checked there and never sent anywhere.
  • Hidden before anything is sent. Cloud help only gets a copy with personal details removed: emails, phone, card and account numbers, addresses, names in greetings.
  • You’re in control. Turn cloud help off and Scamouflage works on-device only. Automatic checks never use the cloud.
  • Nothing sold, no ads. Results are kept only for your browser session. Family sharing stores a short summary, never the message.

In this web demo, anything you paste stays in your browser unless cloud help is needed, and then only the redacted copy is sent.

Get the Chrome extension

  1. Download scamouflage.zip and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and choose the unzipped folder.
  4. Open Gmail, click the Scamouflage icon, and follow the 3-step setup.
